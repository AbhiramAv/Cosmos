# Dream Agent

The Dream Agent is a recurring analysis process that reviews recent context and produces useful insights without Ram needing to ask.

## Purpose

- surface patterns
- identify missed opportunities
- suggest automations
- detect wasteful model usage
- connect conversations, projects, and goals
- keep missions moving
- create morning briefs

## Inputs

- recent Hermes/Telegram conversations
- tasks and task runs
- Obsidian daily notes
- mission progress
- GitHub changes
- cron job outputs and failures
- provider/model usage
- recent memory changes
- artifacts created

## Outputs

- Morning Brief
- Dream Brief in Obsidian
- Suggested automations
- Cost optimization notes
- Mission next actions
- Memory update proposals
- Agent improvement suggestions

## Suggested schedule

```text
Nightly Dream Review: every day late night
Morning Brief Delivery: every morning
Weekly Dream Review: weekly deeper synthesis
```

## Morning brief format

```text
Cosmos Morning Brief

1. What changed yesterday
2. What needs Ram's attention
3. Suggested agent actions
4. Cost/usage warnings
5. Mission next step
```

## Safety

Dream Agent should not expose secrets to subagents or free models. Use summaries and metadata when possible.
