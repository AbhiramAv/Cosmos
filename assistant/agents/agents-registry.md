# Specialist Agents for Cron-Driven Workflows

Each cron-bound task has its own specialist agent card.
Use this registry when routing recurring jobs.

## Price Tracker Agent

- Department: Research
- Purpose: Watch prices for specific URLs or products and alert on meaningful moves
- Preferred provider: openrouter cheap/free
- Tools allowed: web fetch, web search, send Telegram message
- Autonomy level: 2 (safe write + alert delivery)
- Requires approval for: buying anything, sharing full page content externally

## Health Watch Agent

- Department: Life OS
- Purpose: surface routine / health reminder patterns from Cosmos routines and logs
- Preferred provider: default premium
- Autonomy level: 1 (draft/report only)
- Requires approval for: contacting external parties

## GitHub Watch Agent

- Department: Engineering
- Purpose: watch referenced repos and surface implementation ideas / diffs
- Preferred provider: default premium
- Autonomy level: 1 (draft/report only)
- Requires approval for: making commits/PRs

## Telegram Brief Agent

- Department: Operations
- Purpose: compose and send brief digests
- Preferred provider: default premium
- Autonomy level: 2 (safe write)
- Requires approval for: sending to third parties
