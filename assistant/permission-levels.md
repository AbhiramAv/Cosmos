# Cosmos Permission Levels

## Level 0 — Read-only

Can search, inspect, summarize, and report.

## Level 1 — Draft-only

Can draft messages, plans, issues, PR descriptions, documents, and actions without sending or publishing.

## Level 2 — Safe write

Can update non-sensitive notes, tasks, logs, artifacts, dashboard files, and repo docs.

## Level 3 — External action

Can send, publish, deploy, invite, or modify external systems only with approval unless Ram has explicitly authorized the specific recurring workflow.

## Level 4 — High-risk

Always confirm. Includes deletion, money, credentials, security settings, medical/legal/financial decisions, and broad data sharing.
