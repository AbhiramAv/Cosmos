# App Studio Department

Mission: Design and build iOS and web apps, from spec to tested build.

Staff agents:

- [App Architect](app-architect/card.yaml) — Turns an app idea into a buildable spec: screens, data model, tech stack, milestones.
- [UI Designer](ui-designer/card.yaml) — Mockups, design system, app icon, and App Store screenshots.
- [iOS Builder](ios-builder/card.yaml) — Writes Swift/SwiftUI code and manages the Xcode project. Builds are saved and tested locally; nothing is submitted to the App Store without explicit approval.
- [Web Builder](web-builder/card.yaml) — Builds web apps, frontend and backend; can ship preview links.
- [QA Tester](qa-tester/card.yaml) — Tests builds, reproduces bugs, and verifies fixes before release.
- [Release Manager](release-manager/card.yaml) — TestFlight builds, App Store submissions, and versioning. Acts only when Ram says an app qualifies for submission.
