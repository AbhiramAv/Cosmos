# Cosmos

Private personal AI assistant configuration and life OS for Ram.

This repository is intended to hold durable, user-approved context and configuration for building a personal AI assistant system.

## Privacy note

Do not commit raw passwords, API keys, access tokens, recovery codes, or financial secrets. Use encrypted storage or a password manager for secrets.

## Structure

- `profile/` — stable personal context Ram explicitly chooses to store
- `assistant/` — assistant operating principles, recurring tasks, and prompt notes
- `logs/` — placeholder for non-sensitive local logs or exported summaries
