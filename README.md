# Cosmos

Private personal AI assistant configuration and life OS for Ram.

Cosmos is being developed into Ram's Agentic OS: a hierarchical multi-agent system where a CEO/orchestrator agent manages specialist agents, memory, projects, automations, usage, artifacts, and dashboards.

## Privacy note

Do not commit raw passwords, API keys, access tokens, recovery codes, or financial secrets. Use encrypted storage, Hermes auth/config, environment variables, or a password manager for secrets.

## Structure

- `profile/` — stable personal context Ram explicitly chooses to store
- `assistant/` — CEO agent soul, operating principles, model routing, permissions, recurring tasks, and prompt notes
- `docs/` — Cosmos Agentic OS blueprint, dashboard, memory, provider routing, Supabase, cron, and Obsidian design docs
- `obsidian-templates/` — starter Markdown templates for the Obsidian second brain
- `logs/` — placeholder for non-sensitive local logs or exported summaries
